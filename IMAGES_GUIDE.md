## 📂 Exact Folder Path

Copy all images to:
```
d:\Construction_site\static\images\
```

## ✅ Steps

1. **Prepare your images**
   - Resize to recommended sizes
   - Save as JPG format
   - Name them exactly as shown above

2. **Copy to folder**
   ```
   d:\Construction_site\
   └── static\
       └── images\
           ├── about-construction.jpg
           ├── project-1.jpg
           ├── project-2.jpg
           ├── project-3.jpg
           └── project-4.jpg
   ```

3. **Refresh website** (Ctrl + F5 in browser)

4. **Done!** Images will appear automatically

## 💡 Tips

- If image is missing, purple placeholder appears
- Images zoom on hover
- Works on mobile too
- Keep files under 500KB each
